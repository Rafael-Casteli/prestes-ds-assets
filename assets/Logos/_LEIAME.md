# Logos

São os arquivos originais da marca Prestes (RGB), com as cores do brandbook. Use sempre estes arquivos e nunca redesenhe a marca.

- `Prestes_Logo_Horizontal_Positiva_RGB.svg`: para fundo claro. Letras pretas, P verde-prestes e miolo verde-escuro.
- `Prestes_Logo_Horizontal_Negativa_RGB.svg`: para fundo verde-escuro ou preto. Letras e P brancos, miolo verde-prestes.
- `Prestes_Logo_Vertical_Positiva_RGB.svg` / `..._Negativa_RGB.svg`: versão vertical, com as mesmas regras.
- `Prestes_Simbolo_Positivo_RGB.svg` / `..._Negativo_RGB.svg`: o símbolo P isolado, para avatar e espaços pequenos. Não substitui a marca.
- `Prestes_Avatar_*.svg`: avatar para os perfis nas redes, em cinco versões (principal, fundo branco, fundo verde, monocromático positivo e monocromático negativo). Use só como foto de perfil.
